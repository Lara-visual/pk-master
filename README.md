# Лендинг «Компьютерный мастер Сергей Лисовский»

Адаптивный одностраничный сайт компьютерного мастера из Саратова — портфолио-кейс по вёрстке, дизайну и интерактиву. Контакты и примеры работ приведены в качестве демонстрационного наполнения макета.

## Запуск

Проект статический — сборщик не нужен.

```bash
# Вариант 1: Python
python -m http.server 8000

# Вариант 2: любой другой статический сервер (например, npx serve)
```

Откройте `http://localhost:8000/`. **Не открывайте `index.html` двойным щелчком (`file://`)** — в этом случае Яндекс блокирует встраивание формы (`Сайт forms.yandex.ru заблокирован`), потому что у локального файла нет нормального адреса сайта (origin `null`). Форма работает только по `http://localhost` или HTTPS.

## Структура

```
├── index.html              — основной лендинг (все секции, модалки, SEO, JSON-LD)
├── privacy.html            — политика обработки персональных данных
├── favicon.svg             — фавикон
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/styles.css      — стили, палитра, адаптив
    ├── js/main.js          — меню, модалки, портфолио, форма, аналитика
    ├── fonts/              — локальные Manrope и Inter (кириллица + латиница)
    └── img/                — оптимизированные WebP + OG-обложка
```

## Интерактив

- Якорная навигация, scroll-spy, мобильное меню, sticky-панель связи на телефонах.
- Все 15 CTA-кнопок открывают модальное окно со встроенной Яндекс Формой записи.
- Форма занимает до 900 px в ширину на десктопе и всю ширину экрана на телефоне.
- Модальное окно проектов с переключением (prev/next).
- Кнопка Telegram закреплена на всех экранах.

## Форма заявки

Встроена Яндекс Форма — код целиком лежит в `#leadDialog` файла `index.html`:

```html
<script src="https://forms.yandex.ru/_static/embed.js"></script>
<iframe src="https://forms.yandex.ru/u/6b03f4db4a052d088f7f65fb?iframe=1" &theme=dark frameborder="0" name="ya-form-6b03f4db4a052d088f7f65fb" width="650"></iframe>
```

Ответы и уведомления настраиваются в кабинете Яндекс Форм. Интеграции с Google Таблицами и `Code.js` в проекте нет.

В `window.SITE_CONFIG` (`index.html`) заданы телефон, Telegram, `metrikaId` и `ga4Id`. Поле `formEndpoint` и старая логика отправки в `main.js` остались в коде, но не используются: все CTA открывают встроенную форму.

- `metrikaId` / `ga4Id` — при непустых значениях подключаются счётчики, события `cta_click` и др.
- Замените телефон, Telegram/VK и домен `https://lisovsky-pc.ru/` в `index.html`, `sitemap.xml`, `robots.txt` и JSON-LD на значения заказчика перед публикацией.
